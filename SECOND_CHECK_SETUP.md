# Protect the Second Check — deployment and GHL routing

## Current build

- Public funnel: `/protect-second-check/`
- Confirmation page: `/protect-second-check/thank-you.html`
- Cloudflare Pages Function: `/api/second-check-lead`
- Git branch: `protect-second-check-v1`
- All submissions must be assigned to Tony Geer only.

## Cloudflare setting

Create one encrypted Pages environment variable:

- `GHL_SECOND_CHECK_WEBHOOK_URL` = the inbound-webhook URL generated by the GHL workflow below.

Do not place the webhook URL in browser-side code or commit it to GitHub.

## GHL workflow

Create a workflow named **ASCEND — Protect the Second Check — Tony Only**.

1. Trigger: **Inbound Webhook**.
2. Copy the generated webhook URL into the Cloudflare variable above.
3. Map the incoming fields to contact/custom fields.
4. Create or update the contact using phone and email.
5. Assign the contact owner to **Tony Geer**. Do not use round robin.
6. Add tags:
   - `ASCEND-DIRECT`
   - `PROTECT-SECOND-CHECK`
   - `SENIOR-INCOME-PROTECTION`
   - `VETERAN-HOUSEHOLD` only when the submitted answer indicates veteran or veteran spouse.
7. Create an opportunity in pipeline **Ascend Direct Leads**, stage **New — Second Check**.
8. Send Tony an immediate in-app notification, email and SMS with name, phone, preferred contact time, monthly gap, bridge years, estimated gap, primary goal and veteran-household answer.
9. Send the prospect an immediate confirmation text and email from Ascend.
10. Stop automated follow-up when the prospect replies, books, opts out or is manually moved to an active conversation stage.

## Pipeline stages

1. New — Second Check
2. Attempting Contact
3. Contacted
4. Appointment Set
5. Appointment Sat
6. Application Submitted
7. Approved
8. Placed / Paid
9. Nurture
10. Not Moving Forward

Use pipeline outcomes—not raw lead cost—to evaluate the campaign. The primary economic measurements are cost per contacted prospect, cost per appointment sat, cost per submitted application, cost per placed policy and placed annual premium per advertising dollar.

## Required test before ads

1. Submit one test request from the public page.
2. Confirm the contact appears in GHL.
3. Confirm owner is Tony Geer.
4. Confirm no other user receives or owns the lead.
5. Confirm opportunity and tags are correct.
6. Confirm Tony receives all three alerts.
7. Confirm the prospect confirmation is accurate and includes opt-out language.
8. Confirm the submission values match the form.
9. Move the test opportunity through the pipeline.
10. Remove the test contact before launching ads.
